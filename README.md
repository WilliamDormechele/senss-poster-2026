# SENSS Poster Landing Page

This is a static GitHub Pages landing page for the SENSS Annual Conference poster.

## Files

- `index.html` — the landing page
- `poster.pdf` — print-ready poster PDF
- `assets/senss-logo.png` — SENSS logo
- `assets/uea-logo.png` — UEA logo
- `assets/figure-prisma.png` — PRISMA figure
- `assets/figure-sankey.png` — data integration Sankey figure
- `assets/figure-maturity.png` — implementation maturity figure
- `.nojekyll` — tells GitHub Pages to serve the static files directly

## Before publishing

1. Replace `your.uea.email@uea.ac.uk` in `index.html` with your preferred public research email.
2. Check that no confidential data, unpublished sensitive files, raw HDSS data, or identifiable information are included.
3. Upload all files to a public GitHub repository.
4. Enable GitHub Pages from Settings → Pages → Deploy from branch → main → /root.
